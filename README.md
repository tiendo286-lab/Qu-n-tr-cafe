# Quản trị lịch làm – Milano Coffee & Lela Cafe

Web quản trị nhân sự & lịch làm cho chuỗi cafe (bản web của phần mềm offline *QuanTriLichLamCafe 1.7.6*).

- **Nhân viên** (điện thoại): đăng nhập bằng mã NV, order ca, xem lịch làm, nhận thông báo.
- **Quản lý**: danh mục cơ sở/ca/nhân viên, định biên, lịch cố định, order, xếp lịch tổng & lịch cơ sở, cảnh báo,
  chốt lịch & báo cáo Excel, đánh giá nhân viên & voucher, tài khoản đăng nhập, phân quyền, sao lưu / chuyển dữ liệu ZIP.

Kỹ thuật: Python · FastAPI · Jinja2 · SQLite. Xem [HUONG_DAN.md](HUONG_DAN.md) để chạy thử và [docs/DAC_TA.md](docs/DAC_TA.md) cho đặc tả.

Dữ liệu thật (`du_lieu/`) không nằm trong kho mã này.
